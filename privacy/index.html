개인정보 처리 안내

사진은 업로드하거나 서버에 저장하지 않습니다. 선택한 사진은 브라우저 메모리에서 처리되며 탭을 닫으면 처리 데이터는 사라집니다. 다운로드한 파일은 기기에 남습니다.

GitHub Pages가 사이트를 제공합니다. jsDelivr와 Google에서 AI 코드·모델을 내려받을 때 해당 제공자는 IP 주소 등 일반 접속 정보를 받을 수 있습니다. 사진 데이터는 보내지 않습니다.

현재 광고 스크립트와 분석 도구는 없습니다. 앞으로 Google AdSense를 사용할 경우 쿠키를 사용할 수 있으며, 도입 전에 이 안내와 필요한 동의 절차를 갱신합니다.
